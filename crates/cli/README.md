# bobby-browser

CLI for the Bobby Browser automation runtime.

```bash
cargo install bobby-browser
bobby init
bobby serve
```

Binary name: `bobby`. Package name: `bobby-browser`.

HTTP SDK: [`bobby-browser-client`](https://crates.io/crates/bobby-browser-client)
(Rust) and [`@cavi-ai/bobby-browser`](https://www.npmjs.com/package/@cavi-ai/bobby-browser)
(TypeScript).

Documentation: https://cavi-ai.xyz/docs/bobby-browser
