# Rust SDK

The Rust SDK and `interface_core` authority store issue and verify capability-scoped bearers for in-process or embedded use. See [Quickstart](../introduction/quickstart.md) for a minimal authority sketch.

Workspace crates under `crates/` implement the runtime, gateways, and engines. Build with `cargo build -p cli` and run tests with `cargo test --workspace`.
